# Crimtan consenTag – Google Tag Manager Template

The official Google Tag Manager tag template for the Crimtan consenTag container (v5.0.0).

consenTag is the site-wide Crimtan tag. It loads the pixels and events your Crimtan account team has
configured, so you add it once and Crimtan manages the rest from our side.

## Before you start

You'll need your **[Container ID]** from your Crimtan account manager.

## Installation

1. In Google Tag Manager, go to **Templates → Tag Templates → Search Gallery**.
2. Search for **Crimtan consenTag** and click **Add to workspace**.

## Setup

1. Go to **Tags → New** and choose **Crimtan consenTag** as the tag type.
2. Enter your **[Container ID]**.
3. Select the correct consent environment.
4. Set the trigger to **All Pages**.
5. Preview to check the tag fires, then publish.

## Event tracking

To send events such as purchases or basket value, also install the
[Crimtan Event Snippet template](https://github.com/Crimtan/crimtan-event-snippet-gtm-template).
